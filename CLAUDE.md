# Project Instructions

## Required Task Execution Skill

For implementation, debugging, refactoring, testing, code-review, or other repository changes, follow:

`.claude/skills/project-task-execution/SKILL.md`

Before making changes:

1. Read this skill.
2. Check whether `implementation_plan.md` exists.
3. If it exists and is relevant, use it as implementation context.
4. Follow repository-specific conventions and the user's request.
5. Keep exploration and changes narrowly scoped.
6. Verify the implementation with the smallest relevant tests/checks.

Do not perform broad repository exploration or unrelated refactoring unless required by the task.
